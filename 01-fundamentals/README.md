# Fundamentals

This directory contains beginner-friendly projects designed to build fluency in C++ and core programming concepts.

These projects emphasize:

* Language syntax
* Standard library usage
* Basic performance measurement
* Problem decomposition

## Why This Matters

Strong fundamentals are essential before moving into advanced topics such as concurrency, networking, and systems programming.

Mastery of basics reduces cognitive load when learning complex concepts later.

## Subfolders

### file-analyzer/

A command-line tool for analyzing text files.

Concepts covered:

* File input/output
* String processing
* Data aggregation
* Performance measurement

### benchmarking-playground/

Experiments comparing performance of different approaches.

Concepts covered:

* Timing code execution
* Microbenchmarks
* Cache effects
* Algorithm comparison

### memory-experiments/

Small programs exploring memory behavior.

Concepts covered:

* Stack vs heap
* Memory layout
* Pointer usage
* Allocation costs
