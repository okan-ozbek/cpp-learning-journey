# Algorithms

This directory contains implementations and practice problems focused on algorithmic problem solving and computational complexity.

Algorithms are a core requirement for software engineering interviews, particularly in quantitative trading and high-performance engineering roles where efficiency and correctness under constraints are critical.

The goal of this section is to:

* Strengthen problem-solving skills
* Improve time and space complexity reasoning
* Develop the ability to write correct code quickly
* Build intuition for choosing optimal data structures

## Why This Matters

In low-latency environments, selecting the wrong algorithm or data structure can introduce unacceptable performance overhead. Strong algorithmic foundations enable engineers to reason about performance trade-offs and implement efficient solutions under strict time constraints.

## Subfolders

### leetcode-solutions/

Contains solutions to algorithmic problems from LeetCode.

Focus areas include:

* Arrays and hashing
* Trees and graphs
* Dynamic programming
* Greedy algorithms
* Binary search
* Bit manipulation

Each solution emphasizes clarity, correctness, and performance analysis.

### cses-solutions/

Contains solutions to problems from the CSES problem set.

CSES provides structured algorithm training across multiple domains and is useful for reinforcing theoretical concepts with implementation practice.

Problems here are typically more academic and help build deeper algorithmic understanding.
