# Networking

This directory contains projects related to network programming and communication protocols.

Networking is fundamental to distributed systems and is especially important in trading infrastructure where systems communicate with exchanges and market data feeds in real time.

The goal of this section is to develop:

* Socket programming skills
* Understanding of TCP/UDP protocols
* Latency awareness
* Asynchronous communication patterns

## Why This Matters

Low-latency systems depend heavily on efficient network communication. Engineers must understand how data moves across machines and how to minimize delays introduced by networking layers.

## Subfolders

### tcp-chat-server/

A multi-client TCP chat server.

Concepts covered:

* Socket APIs
* Client/server architecture
* Concurrent connections
* Message broadcasting

### udp-experiments/

Experiments with UDP communication.

Concepts covered:

* Connectionless protocols
* Packet handling
* Latency measurements
* Reliability trade-offs
