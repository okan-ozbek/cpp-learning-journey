# Systems Programming

This directory focuses on low-level programming concepts that interact closely with the operating system and hardware.

Systems programming involves understanding how software uses memory, CPU resources, and operating system services.

The projects here aim to develop:

* Memory management knowledge
* OS interaction
* Performance awareness
* Resource control

## Why This Matters

High-frequency trading systems operate under strict latency constraints. Engineers must understand how software interacts with hardware and the operating system to eliminate bottlenecks.

Systems knowledge differentiates high-performance engineers from general application developers.

## Subfolders

### memory-allocator/

A custom memory allocator implementation.

Concepts covered:

* Heap management
* Fragmentation
* Allocation strategies
* Low-level memory control

### file-io-benchmarks/

Experiments measuring file I/O performance.

Concepts covered:

* Buffered vs unbuffered I/O
* System calls
* Throughput and latency measurement
